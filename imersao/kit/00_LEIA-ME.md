# Kit da Imersão, 19/09/2026

Bem-vindo. Este é o kit que você leva para casa. Aqui está a ordem de uso, do início ao fim do dia.

## Ordem de uso no dia, pelas 5 partes do guia

**Parte 1, fundamentos.** Nenhuma peça do kit é usada aqui. Só o instrutor fala.

**Parte 2, a tela do Claude Desktop.**
1. **01_O_CAMINHO_DO_CASO.md**: use no bloco 2.1 (sobrevoo das abas), com caneta na mão, para marcar onde você perde mais tempo hoje.

**Parte 3, skills, plugins, agentes e rotinas.**
2. **03_SKILL_ESQUELETO/SKILL.md** e **05_SKILL_JURIS360_VIABILIDADE/**: use no bloco 3.1. Primeiro você cria a sua skill de jurisprudência e viabilidade a partir do esqueleto e do `PASSO_A_PASSO_criar_junto.md` desta pasta; depois compara com o gabarito completo em `SKILL.md`.
3. **06_PLUGIN_PETICAO_INICIAL_CIVEL/**: use no bloco 3.3. Plugin pronto: siga `INSTALAR.md` para instalar (caminho A, plugin, ou caminho B, skill avulsa), depois rode com `/peticao` ou pedindo a skill pelo nome.
4. **07_AGENTE_ESPECIALISTA/**: use no bloco 3.4, depois do almoço. Preencha `AGENTE_ESQUELETO.md` e siga `PASSO_A_PASSO_criar_junto.md` para criar o "Especialista da minha área".
5. **04_SKILL_DJEN_do_dia/**: use no bloco 3.5. A pasta tem a skill pronta e o passo a passo da rotina local.

**Parte 4, infraestrutura de IA.**
6. **08_INFRAESTRUTURA/ARVORE_DE_PASTAS.md** e **NOMENCLATURA.md**: use no bloco 4.1.
7. **08_INFRAESTRUTURA/INFRAESTRUTURA_ESQUELETO.md**: use no bloco 4.2, copiando para a pasta do escritório como `INFRAESTRUTURA.md`.
8. **02_CLAUDE_md_do_escritorio_ESQUELETO.md**: use no bloco 4.3, copiando para a pasta do seu escritório como `CLAUDE.md`, com prova de leitura na aba Code.
9. **08_INFRAESTRUTURA/BRAND_VOICE_ESQUELETO.md** e **DESIGN_SYSTEM_ESQUELETO.md**: use no bloco 4.4, se sobrar tempo. Senão, levam para casa como esqueleto.

**Parte 5, execução no caso simulado.**
10. **06_CHECKLIST_DE_VERIFICACAO.md**: use no bloco 5.5 (folha inteira), para conferir um julgado da própria saída no site do tribunal.
11. **09_NORMAS_E_CLAUSULA.md**: dois minutos no fecho da parte 5, e leitura completa em casa.
12. **11_SEGUNDA_DE_MANHA.md**: a última coisa dita no dia. É o que você faz assim que chegar ao escritório na segunda.

## Consulta livre, o dia inteiro

- **07_FAQ.md**: as quatro dúvidas que sempre travam a sala. Consulte quando a dúvida aparecer.
- **08_GLOSSARIO.md**: uma página, na voz do Matheus, para qualquer termo técnico que você não lembrar.

## Se você não trouxe o modelo de peça do seu escritório

Use o caso de consumidor completo, entregue à parte pelo instrutor, como base para a sua skill.
