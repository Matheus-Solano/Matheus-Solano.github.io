# POP, procedimento operacional padrão

> Um POP é regra GERAL, do escritório, de uma área ou de uma ação. Vale para todos os agentes e mora aqui, na infraestrutura. É diferente da SOUL, que é a alma pessoal de um único agente (ver `07_AGENTE_ESPECIALISTA\SOUL_ESQUELETO.md`).

Copie este arquivo para `POP_[nome_do_procedimento].md`, nesta mesma pasta, um por procedimento.
