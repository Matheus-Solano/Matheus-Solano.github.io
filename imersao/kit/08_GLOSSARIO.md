# Glossário, na voz dele

**Harness.** É a estrutura, a tela ou o programa que você usa para trabalhar com a IA. O chat do navegador é um harness, o terminal é outro. Pensa assim: o harness é o carro que te move, e você é o raciocínio.

**Token.** É a moeda de troca do modelo, o salário dele. Cada trecho de conversa consome um pulso, como numa ligação telefônica antiga.

**Contexto.** É a base de informação que você dá para o modelo trabalhar. É a mesa de trabalho do advogado: só cabe uma certa quantidade de processo aberto antes de começar a empilhar e perder coisa de vista.

**Esforço.** É o tempo que o modelo gasta processando o que você pediu. Menos esforço, mais rápido e menos capricho. Mais esforço, mais devagar e mais capricho. Use o padrão, na dúvida.

**Modelo júnior, pleno e sênior.** Pensa no modelo maior como o sócio sênior do escritório: mais capaz, precisa de menos orientação, mas custa mais caro. O modelo pequeno é o estagiário rápido, bom para triagem simples.

**Chat, Cowork e Code.** Chat é conversar. Cowork mexe no seu computador. Code comanda uma equipe de robôs, dentro das suas pastas.

**MCP, o conector.** É um adaptador de tomada. O seu agente pluga numa ferramenta externa em vez de responder de memória. Se responde de memória, ele lembra. Se responde pela tomada, ele consulta.

**Plugin.** É como uma skill mais elaborada, com mais ferramentas dentro. Se a skill cuida de uma tarefa, o plugin é o departamento inteiro.

**Subagente.** É o modelo chamando, dentro dele mesmo, pequenos funcionários com contexto menor para resolver uma tarefa específica. Diminui o tempo e melhora a qualidade.

**Alucinação.** A IA erra, e ela erra feio, e ela erra com convicção. Às vezes ela inventa. Às vezes a informação existe, mas ela entendeu errado, e o sentido sai ao contrário do original. A regra é a mesma nos dois casos: verificar tudo.

**Prompt injection.** É uma estratégia ilegal e antiética de manipular a IA, embutindo comando escondido dentro da própria petição, com fundo branco e letra pequena, para que a IA do tribunal siga aquela ordem sem que ninguém perceba.

**Metaprompt.** Usar uma IA para escrever o prompt que outra vai executar. Faça isso em ferramenta gratuita, sem colar dado de cliente.

**Segundo cérebro.** É só um termo bonito para uma organização de pastas e subpastas no seu computador, com tudo que orienta como o seu agente deve trabalhar.

**CLAUDE.md, o arquivo de memória.** É o memorial de instruções que você deixaria fixado na parede para um estagiário novo. Ele lê antes de tocar em qualquer processo.

**SOUL.** É a alma pessoal de um agente: a personalidade, o jeito de atuar, o tom, por escrito, não na cabeça de alguém.

**POP.** É o procedimento operacional padrão, a regra geral do escritório, de uma área ou de uma ação. Vale para todos os agentes e mora na infraestrutura, não dentro de uma skill só.

**Guard raios (guardrails).** Os limites escritos do agente. Por exemplo: nunca inventar jurisprudência, nunca citar sem conferir, nunca expor dado de cliente.

**Skill.** É uma habilidade que você dá ao seu agente, um conjunto de instruções pré-definidas para que ele repita a mesma tarefa, do mesmo jeito, todas as vezes.

**One shot (um tiro só).** É pedir tudo de uma vez, e esperar que a IA vomite a peça pronta para só conferir e protocolar. Nunca funciona bem. Nada em um tiro só.

**"Petição com cara de IA".** É o produto genérico que sai do tiro único. Pode até não estar juridicamente errado, mas é um conteúdo ruim.

**Chrom.** É a tarefa agendada, o que você põe para o agente fazer sozinho, em horário marcado.

**Vault.** É o acervo pessoal, o segundo cérebro, o cofre.

**Tela preta.** É o terminal. Serve para coisa rápida. Para trabalho longo, use um ambiente com interface.

**Artefato.** É o documento ou mini-aplicação que a IA gera como resultado: uma peça, uma planilha, uma página, pronta para usar fora da conversa. É o que sai da mesa do estagiário já pronto para juntar aos autos, não um rascunho de bate-papo.

**Markdown.** É um formato de texto simples, sem formatação de editor, que qualquer sistema de IA lê e escreve nativamente.
