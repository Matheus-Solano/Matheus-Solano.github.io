## Prontuário do caso

> Isto não é para preencher agora. É a explicação de como a memória de cada caso deve nascer, para você lembrar depois. Deixe assim mesmo, comentado.

Cada caso tem a própria pasta, dentro de `[NOME DO ESCRITÓRIO]/[NOME DO CLIENTE]/[NOME DO CASO]`. Dentro da pasta do caso, o Claude cria e mantém um arquivo de memória próprio do caso (o prontuário), com o que já foi decidido, o que está pendente e o porquê de cada decisão. Você não escreve esse arquivo à mão: você pede para o Claude criar, e pede atualização ao final de cada etapa relevante. Não se apaga a memória para recomeçar. Se algo estiver errado, você reeduca, acrescentando uma linha nova, nunca reescrevendo tudo.
